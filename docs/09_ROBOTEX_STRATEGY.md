# Robotex Strategy

## Pitch spine

**Problem → User → Solution → Working proof → Difference → Value → Business → Future.**

Suggested opening: “When a student misses one day of school, finding out what they missed should not depend on chasing friends or searching a noisy group chat.”

## 60–90 second product demonstration

| Time | Presenter action | Point to say |
|---|---|---|
| 0–10s | State the missed-information problem. | “Important learning instructions get scattered.” |
| 10–25s | Teacher signs in and publishes a short Grade 7 Science update. | “A teacher enters the class, task, and deadline once.” |
| 25–45s | Switch to linked parent; show live update and parent acknowledgement. | “Parents receive trusted child-specific information, not guesses.” |
| 45–60s | Return to teacher status; refresh/reopen to show persistence. | “The teacher sees acknowledgement. This is stored securely, not a mock button.” |
| 60–70s | Open principal coverage. | “The principal sees own-school communication coverage from the same records.” |
| 70–90s | State differentiator/business/future. | “We focus on one continuity loop; schools can pilot it then subscribe.” |

## Presentation discipline

- Demonstrate one update from start to finish; never tour every screen.
- Preload realistic fictional data and start in the teacher account.
- Have the three demo tabs/browser profiles prepared, but explain the role switch honestly.
- Use a visible “demo data” badge; no real child information.
- Keep a 30-second recorded backup on the device, but say clearly if it is a backup.
- Do not claim users, savings, accuracy, AI, or partnerships unless documented and true.

## Exhibit assets to prepare later

- One-page problem/solution board.
- Architecture card: “website → secure sign-in → database.”
- Privacy card: minimal data, permissions, fictional demo data.
- Pilot feedback board with real anonymised quotes only after interviews.
- A simple QR code for judges to access a safe read-only/demo environment.

## Differentiator in one line

“EduBridge does not try to run the whole school; it closes the small but costly gap between a classroom instruction and a family knowing what happens next.”
