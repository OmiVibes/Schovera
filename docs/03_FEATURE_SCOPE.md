# Feature Scope

## V1 communication loop

| Feature | Value | First-slice status |
|---|---|---|
| Teacher/Parent/Principal sign-in | Real role-aware access | Required |
| Assigned class and student selection | Prevents misdirected updates | Required |
| Structured student update | Category, title, message, importance, timestamp | Required |
| Parent child inbox/timeline | Child-specific trusted information | Required |
| Parent acknowledgement | Records “seen” with time | Required |
| Teacher acknowledgement status | Shows follow-up need | Required |
| Principal communication coverage | Truthful own-school aggregate | Immediately after core loop |
| Attendance, announcements, attachments | Secondary modules | Deferred until core gate |

## Excluded

Student login; fees; exams/marks/report cards; timetable; chat/social features; AI; teacher ranking; payment; native mobile app; microservices; fake analytics; and any unapproved feature. No button may imply a feature that is unavailable.
